# cp0x 的 Hyperliquid 资产找回界面

语言：[English](./README.md) | [中文](./README_CH.md)

这是一个用于从 Hyperliquid 提取资产的无许可界面，专为钱包地址被官方 app.hyperliquid.xyz 屏蔽的用户构建。

Hyperliquid 会根据钱包地址和地理位置限制对其界面的访问。此界面直接与协议的智能合约交互，绕过任何前端限制。无需注册、不受地理封锁，也没有中间人。

## 链接

- 网站：[hlrecovery.cp0x.com](https://hlrecovery.cp0x.com/)
- 无许可界面：[pi.cp0x.com](https://pi.cp0x.com/)
- Twitter：[@cp0xdotcom](https://x.com/cp0xdotcom)
- Telegram：[@cp0xdotcom](https://t.me/cp0xdotcom)

## 功能

- 取消未成交订单
- 平仓永续头寸
- 卖出现货资产
- 提取金库资金
- 偿还借款或提取组合保证金借贷头寸
- 解除 HYPE 质押委托
- 提取资产

连接钱包，或粘贴任意地址以只读模式查看。所有操作都在本地签名——我们绝不会访问你的密钥或资金。
